# Team Evaluation Scripts

Scripts for team evaluation and metrics tracking.

## Scripts

### `setup_team_evaluation.py`
Initial setup for team evaluation system.

```bash
python scripts/team_evaluation/setup_team_evaluation.py
```

### `run_team_evaluation.py`
Run team evaluation calculations.

```bash
python scripts/team_evaluation/run_team_evaluation.py
```

### `manual_team_evaluation.py`
Manual team evaluation runner.

```bash
python scripts/team_evaluation/manual_team_evaluation.py
```
