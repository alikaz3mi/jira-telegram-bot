# Debug and Inspection Tools

Utility scripts for debugging, checking status, and inspecting data.

## Scripts

### Status Checkers

#### `check_boards.py`
Check Jira boards configuration.

```bash
python scripts/debug_tools/check_boards.py
```

#### `check_calculation_logs.py`
Inspect calculation logs.

```bash
python scripts/debug_tools/check_calculation_logs.py
```

#### `check_task_tracking_progress.py`
Check task tracking progress.

```bash
python scripts/debug_tools/check_task_tracking_progress.py
```

### Debug Tools

#### `debug_epic_fields.py`
Debug epic field mappings.

```bash
python scripts/debug_tools/debug_epic_fields.py
```

### Demo Scripts

#### `demo_synth_pm_filtering.py`
Demonstrate SynthPM filtering capabilities.

```bash
python scripts/debug_tools/demo_synth_pm_filtering.py
```

### View Scripts

#### `view_jira_tasks_delay_reasons.py`
View delay reasons for Jira tasks.

```bash
python scripts/debug_tools/view_jira_tasks_delay_reasons.py
```

#### `find_recent_sprints.py`
Find recent sprints.

```bash
python scripts/debug_tools/find_recent_sprints.py
```

## Usage

These scripts are primarily for development, debugging, and inspection purposes.
