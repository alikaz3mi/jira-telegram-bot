# Report Generation Scripts

Scripts for generating and scheduling reports.

## Scripts

### `run_scheduled_reports.py`
Long-running service for automated report generation.

```bash
python scripts/reports/run_scheduled_reports.py
```

### `generate_reports_once.py`
Generate reports once (ad-hoc).

```bash
python scripts/reports/generate_reports_once.py
```

### `generate_random_tasks.py`
Generate random test tasks for development.

```bash
python scripts/reports/generate_random_tasks.py
```

## Configuration

Configure report settings in `.env` file.
