# راهنمای کامل سیستم ارزیابی تیم (Team Evaluation System)

## مقدمه

این سیستم یک چارچوب جامع برای ارزیابی عملکرد اعضای تیم توسعه در هر اسپرینت است. امتیاز نهایی بر اساس ترکیب **ارزیابی سیستمی (70%)** و **ارزیابی مدیر (30%)** محاسبه می‌شود.

---

## ساختار امتیازدهی

### امتیاز نهایی (Final Score)
```
امتیاز نهایی = (امتیاز سیستمی × 0.7) + (امتیاز مدیر × 0.3)
```

### بخش اول: امتیاز سیستمی (System Score) - 70%

این بخش به صورت خودکار بر اساس داده‌های جیرا محاسبه می‌شود:

#### چهار معیار اصلی:

1. **رعایت ددلاین (25%)**
   - پنالتی تأخیر: 2 امتیاز به ازای هر روز تأخیر (بعد از 2 روز grace period)
   - پاداش تحویل زودهنگام: 5 امتیاز به ازای هر روز زودتر
   - ضریب متغیر بر اساس تعداد تسک‌ها (1 تسک = 15 امتیاز/روز، 10+ تسک = 5 امتیاز/روز)
   - ضریب اولویت: Highest ×1.0, High ×0.6, Medium/Low ×0.2

2. **ثبت زمان (20%)**
   - امتیاز = (ساعت ثبت شده ÷ ساعت مورد انتظار) × 100
   - پنالتی عدم ثبت زمان: -30 امتیاز
   - پنالتی ثبت ناکافی (کمتر از 65%): تا -30 امتیاز

3. **تسک‌های اولویت بالا (40%)** - مهمترین معیار
   - انتظار: 50% زمان صرف تسک‌های Highest/High شود
   - هیچ تسکی تکمیل نشده: -50 امتیاز
   - 100% تکمیل: 100 امتیاز

4. **کیفیت کد (15%)**
   - باگ‌های پشتیبانی: آستانه 0.3 باگ/استوری، پنالتی تا -30
   - باگ‌های تستر: آستانه 0.4 باگ/استوری، پنالتی تا -30
   - حداکثر پنالتی کل: -60 امتیاز

#### فرمول محاسبه امتیاز سیستمی:
```
امتیاز سیستمی = 
    (امتیاز ددلاین × 0.25) +
    (امتیاز ثبت زمان × 0.20) +
    (امتیاز اولویت بالا × 0.40) +
    (امتیاز کیفیت × 0.15) +
    پاداش تسک‌های اضافی -
    پنالتی ثبت زمان ناکافی
```

---

### بخش دوم: امتیاز مدیر (Manager Score) - 30%

این بخش توسط مدیر فنی یا مدیر محصول به صورت ماهانه تعیین می‌شود و جنبه‌های کیفی عملکرد را می‌سنجد.

#### دو معیار اصلی:

1. **همراهی با مدیر و مشارکت در دلیوری‌ها (15% از کل)**
   - تعهد به زمان‌بندی
   - خلاقیت و ارائه راهکار
   - روحیه تیمی و همکاری
   - مسئولیت‌پذیری

2. **همسویی با اولویت‌های رشد شرکت (15% از کل)**
   - درک از اهداف کلان شرکت
   - تمرکز بر اولویت‌های استراتژیک
   - انعطاف‌پذیری و یادگیری
   - کار در حوزه‌های حیاتی

#### محدوده امتیاز مدیر:
- حداقل: 0 (عملکرد بسیار ضعیف)
- متوسط: 50-70 (عملکرد معمولی)
- عالی: 85-100 (عملکرد استثنایی)

---

## مثال محاسبه

### مثال 1: توسعه‌دهنده با عملکرد خوب

**امتیازات سیستمی:**
- ددلاین: 85 × 0.25 = 21.25
- ثبت زمان: 90 × 0.20 = 18.00
- اولویت بالا: 80 × 0.40 = 32.00
- کیفیت: 75 × 0.15 = 11.25
- **جمع امتیاز سیستمی: 82.5**

**امتیاز مدیر: 75**

**امتیاز نهایی:**
```
Final Score = (82.5 × 0.7) + (75 × 0.3)
            = 57.75 + 22.5
            = 80.25 ≈ 80
```

---

### مثال 2: توسعه‌دهنده با امتیاز سیستمی بالا، ارزیابی مدیر پایین

**امتیازات سیستمی: 90**
**امتیاز مدیر: 40** (همراهی پایین)

**امتیاز نهایی:**
```
Final Score = (90 × 0.7) + (40 × 0.3)
            = 63 + 12
            = 75
```

⚠️ **نکته:** حتی با امتیاز سیستمی عالی، عدم همکاری با تیم می‌تواند امتیاز نهایی را کاهش دهد.

## تأثیر امتیاز بر پاداش

پاداش حسن انجام کار معادل **10% حقوق پایه** است که بر اساس امتیاز نهایی تخصیص می‌یابد:

| امتیاز نهایی | درصد پرداخت | توضیحات |
|--------------|-------------|---------|
| 0-30 | 0% | امتیاز منفی در سوابق |
| 30-50 | 0% | بدون پاداش |
| 50-60 | 50% | نیمی از پاداش |
| 60-70 | 75% | سه چهارم پاداش |
| 70-80 | 100% | پاداش کامل |
| 80-90 | 110% | پاداش + 10% بونوس |
| 90-100 | 120% | پاداش + 20% بونوس |

## نکات کلیدی برای بهبود امتیاز

### برای افزایش امتیاز سیستمی (70%)

1. **ددلاین (25%)**
   - تسک‌های Highest را در اولویت قرار دهید
   - تحویل زودهنگام پاداش دارد (+5 امتیاز/روز)
   - از تأخیرهای طولانی جلوگیری کنید (-2 امتیاز/روز)

2. **ثبت زمان (20%)**
   - حداقل 65% ساعت مورد انتظار ثبت کنید
   - ثبت روزانه انجام دهید (نه آخر هفته)

3. **اولویت بالا (40%)**
   - 50% زمان را صرف تسک‌های مهم کنید
   - تکمیل یک تسک مهم بهتر از شروع چند تسک است

4. **کیفیت (15%)**
   - تست کامل قبل از تحویل
   - Code review دقیق
   - کاهش باگ‌های تولید شده

### برای افزایش امتیاز مدیر (30%)

1. **همراهی (15%)**
   - پاسخگویی سریع به درخواست‌ها
   - همکاری در زمان‌های بحرانی
   - ارائه راهکارهای خلاقانه

2. **همسویی (15%)**
   - درک و پیگیری اهداف شرکت
   - یادگیری تکنولوژی‌های موردنیاز
   - مشارکت در پروژه‌های استراتژیک

## پرسش‌های متداول

### Q: چرا امتیاز من منفی شده؟
**A:** امتیاز منفی زمانی اتفاق می‌افتد که:
- هیچ تسک اولویت بالایی تکمیل نشده (-50)
- هیچ زمانی ثبت نشده (-30)
- تأخیرهای شدید در تسک‌های Highest
- ترکیب چند مورد بالا

### Q: چطور می‌توانم امتیاز بالای 100 بگیرم؟
**A:** دو راه:
1. تکمیل تسک‌های اضافی (+3 امتیاز/تسک)
2. امتیاز مدیر بالا (بیش از 90) + امتیاز سیستمی عالی

### Q: تفاوت امتیاز سیستمی و نهایی چیست؟
**A:** 
- **امتیاز سیستمی**: محاسبه خودکار از جیرا (70% وزن)
- **امتیاز مدیر**: ارزیابی انسانی (30% وزن)
- **امتیاز نهایی**: ترکیب وزن‌دار هر دو

### Q: چه زمانی امتیاز مدیر ثبت می‌شود؟
**A:** در پایان هر اسپرینت یا به صورت ماهانه توسط مدیر فنی/محصول

### Q: آیا می‌توانم امتیاز مدیر خود را ببینم؟
**A:** بله، در داشبورد Grafana یا جدول team_evaluation

## مستندات فنی

### جدول دیتابیس
```sql
-- ستون‌های جدید
ALTER TABLE team_evaluation ADD COLUMN manager_evaluation_score INTEGER;
ALTER TABLE team_evaluation ADD COLUMN system_score INTEGER;
ALTER TABLE team_evaluation ADD COLUMN final_score INTEGER;
```

### API برای ثبت امتیاز
```python
from scripts.update_manager_scores import update_manager_score

await update_manager_score(
    evaluation_id=123,
    manager_score=85
)
```

### Query برای Grafana
```sql
SELECT 
    developer_name,
    system_score * 0.7 as system_contribution,
    manager_evaluation_score * 0.3 as manager_contribution,
    final_score
FROM team_evaluation
WHERE sprint_name = 'PARSCHAT SPRINT 50'
ORDER BY final_score DESC;
```

سیستم ارزیابی جدید:
- ✅ **جامع**: هم کمیت (سیستمی) و هم کیفیت (مدیر) را می‌سنجد

- ✅ **شفاف**: فرمول‌ها و محاسبات مشخص
- ✅ **انگیزشی**: پاداش برای عملکرد بالا
- ✅ **قابل پیگیری**: داشبورد Grafana برای نظارت

این چارچوب به تیم کمک می‌کند تا عملکرد خود را بهبود دهد و به اهداف سازمان برسد.
