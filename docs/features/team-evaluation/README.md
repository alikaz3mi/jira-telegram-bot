# Team Evaluation Feature

The team evaluation system provides comprehensive metrics and scoring for development team performance based on task completion, deadlines, and quality indicators.

## 📄 Documentation Files

- **scoring-methodology.md** - 📊 راهنمای فارسی محاسبه امتیاز حسن انجام کار (برای مدیران)
- **team_evaluation_system.md** - Complete system overview, scoring algorithms, and evaluation criteria
- **team_evaluation_cli.md** - Command-line interface documentation for running evaluations

## 🎯 Key Features

- **Performance Scoring**: Multi-dimensional scoring based on deadlines, task completion, and quality
- **Sprint Analysis**: Sprint-level insights and performance tracking
- **Quality Metrics**: Bug tracking and defect analysis
- **Workload Assessment**: Time tracking and productivity analysis
- **CLI Tools**: Command-line utilities for evaluation and reporting

## 📊 Metrics Tracked

- **Deadline Performance**: Early delivery bonuses, late delivery penalties
- **Task Completion**: High-priority task completion rates
- **Quality Indicators**: Bug rates, defect ratios
- **Time Management**: Registered hours vs expected hours
- **Sprint Contribution**: Active sprint participation

## 🚀 Getting Started

1. Configure team evaluation settings in environment variables
2. Set up calendar data for holiday/weekend calculations
3. Configure Google Sheets integration for reporting
4. Run initial team evaluation to establish baselines
5. Set up automated evaluation schedules

For detailed setup and usage instructions, see the individual documentation files.
